# paa-2-trabalho

Trabalho 02 de Projeto e Análise de Algoritmos.

Matrícula: 516833  
Linguagem: Python 3

## Como rodar

É necessário ter o Python 3 instalado.

```bash
python3 questao1.py
python3 questao2.py
```

Os exemplos de entrada já estão no código. A saída aparece no terminal.

## Questões

### Questão 1 — Problema da Balsa

Uma balsa tem duas pistas de comprimento `L` e uma fila de carros com tamanhos diferentes. Os carros devem embarcar na ordem da fila, sem pular ninguém. O algoritmo resolve o problema de embarcar o maior número possível de carros nas duas pistas.

Arquivo: `questao1.py`

### Questão 2 — Organização de Tarefas e Multas

Há `n` tarefas, cada uma com prazo e multa por atraso. Em cada dia roda apenas uma tarefa. O algoritmo resolve o problema de montar uma agenda que minimize o valor total das multas.

Arquivo: `questao2.py`
